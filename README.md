# Moka Pet

책상 위에서 키우는 데스크톱 펫. 알에서 태어나 자라고, 먹인 대로 몸이 바뀌고,
대해준 대로 성격이 잡힙니다. 구글 캘린더를 붙이면 일정도 알려줍니다.

프레임 없는 투명 창이라 배경이 비치고, 펫이 아닌 곳은 클릭이 그대로 통과해
아래 창을 가리지 않습니다. macOS와 Windows에서 돌아갑니다.

---

## 받기

[Releases](../../releases)에서 받으세요.

| | 파일 |
|---|---|
| macOS (Apple Silicon) | `Moka Pet-x.y.z-arm64.dmg` |
| macOS (Intel) | `Moka Pet-x.y.z.dmg` |
| Windows 설치본 | `Moka Pet Setup x.y.z.exe` |
| Windows 무설치 | `Moka Pet x.y.z.exe` |

서명하지 않은 빌드라 처음 열 때 경고가 뜹니다. macOS는 우클릭 → 열기,
Windows는 SmartScreen에서 "추가 정보" → "실행"을 누르면 됩니다.

새 버전이 나오면 앱이 알려줍니다. 자동으로 설치되지는 않고, 받는 페이지를 열어 줍니다.
(서명 없는 macOS 앱은 스스로를 교체할 수 없습니다.)

## 키우기

**알에서 시작합니다.** 20분쯤 기다리거나 쓰다듬어 주면 깨어나는데,
누가 나올지는 깨져야 압니다. 아홉 마리 중 하나입니다.

**여섯 단계로 자랍니다.** 아기 → 어린이 → 청소년 → 어른 → 장로 → 전설.
단계마다 몸이 길어지고 눈이 작아지고, 장로가 되면 눈썹이 하얗게 셉니다.
잘 돌보면 아기는 닷새, 어른은 한 달쯤 걸립니다.

**어떻게 키우느냐가 그대로 남습니다.**

- **무게** — 간식을 많이 주면 몸이 넓고 낮아지고, 많이 놀아주면 길쭉해집니다.
- **성격** — 쓰다듬으면 `다정`, 놀아주면 `활발`, 간식만 주면 `먹보`, 재우기만 하면 `느긋`.
  성격은 대사만 바꾸는 게 아니라 배고픔·즐거움·에너지가 닳는 속도를 바꿉니다.
- **재주** — 앉아 · 손 · 엎드려 · 빙글 · 점프 · 인사 · 기다려 · 하이파이브 · 구르기 · 노래.
  잘 놀아주고 아껴준 아이가 빨리 배웁니다.

**어른 둘이면 아이가 생깁니다.** 부모 털색을 섞은 세상에 하나뿐인 색으로 태어나고,
부모의 재주를 최대 두 개까지 물려받습니다. 가계도에 남습니다.

돌보기 창(⌘K)에서 밥·간식·놀기·산책·훈련·재우기·치우기, 알아맞히기 놀이,
수집 현황, 가계도, 기록을 볼 수 있습니다.

## 구글 캘린더

설정 창에서 구글 계정을 연결하면 다가오는 일정을 알려줍니다.
읽기 권한(`calendar.readonly`)만 요청하고, 토큰은 OS 키체인에 암호화해 보관합니다.

직접 빌드해서 쓰시려면 구글 클라우드 콘솔에서 **데스크톱 앱** OAuth 클라이언트를
만들어 저장소 루트에 `google-client.json`으로 두세요. 이 파일은 커밋되지 않습니다.

```json
{ "clientId": "...", "clientSecret": "..." }
```

## 구조

| 파일 | 하는 일 |
|---|---|
| `main.js` | 창·트레이·메뉴·설정, 모든 것을 잇는 곳 |
| `care.js` | 키우기 규칙 전부. 화면 없이 테스트됩니다 |
| `chatter.js` | 펫이 하는 말 |
| `calendar.js` · `google-auth.js` | 구글 캘린더와 OAuth |
| `updater.js` | 새 버전 확인 |
| `renderer/pixel.js` | 도트맵 → SVG 컴파일러 |
| `renderer/species.js` | 아홉 종과 성장 단계별 변형 |
| `renderer/gear.js` | 소품 네 슬롯 |

그림은 전부 코드입니다. 이미지 파일이 아니라 48×48 도트맵을 `<rect>`로 펴서 그립니다.
`shape-rendering="crispEdges"`라 어떤 크기에서도 뭉개지지 않습니다.
