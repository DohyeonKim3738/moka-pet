# Moka Pet

책상 위에서 키우는 데스크톱 펫. 알에서 태어나 자라고, 먹인 대로 몸이 바뀌고,
대해준 대로 성격이 잡힙니다. 구글 캘린더를 붙이면 일정도 알려줍니다.

프레임 없는 투명 창이라 배경이 비치고, 펫이 아닌 곳은 클릭이 그대로 통과해
아래 창을 가리지 않습니다. macOS와 Windows에서 돌아갑니다.

---

## 받기

[Releases](../../releases)에서 받으세요.

| | 파일 |
|---|---|
| macOS (Apple Silicon) | `Moka-Pet-x.y.z-macOS-arm64.zip` |
| macOS (Intel) | `Moka-Pet-x.y.z-macOS-x64.zip` |
| Windows | `Moka-Pet-Setup-x.y.z.exe` |

**macOS** — zip 을 풀고 안에 있는 `설치.command` 를 두 번 누르세요.
앱을 응용 프로그램 폴더에 넣고, macOS 가 막는 격리 표시를 떼고, 실행까지 합니다.

> **"열지 않음" 이라고 막히면** — 파란 `휴지통으로 이동` 을 누르지 마세요, 파일이 지워집니다.
> `완료` 를 누르고 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 `그래도 열기` 를 누르면 됩니다.
> 터미널이 편하면 `bash ` 를 치고 `설치.command` 를 창 안으로 끌어다 놓아도 됩니다 —
> macOS 가 막는 것은 두 번 눌러 여는 경우뿐이라, 터미널로는 그냥 실행됩니다.
>
> macOS 15 부터 서명 없는 스크립트는 두 번 눌러 열 수 없고, 예전의 "오른쪽 버튼 → 열기" 도
> 더는 통하지 않습니다. 같은 폴더의 dmg 를 열어 직접 옮기고
> `xattr -dr com.apple.quarantine "/Applications/Moka Pet.app"` 를 한 줄 실행해도 됩니다.

**Windows** — 설치 파일을 실행하세요. 서명이 없어 SmartScreen 이 막으면
"추가 정보" → "실행" 을 누르면 됩니다.

새 버전이 나오면 앱이 알려줍니다. Windows 는 자동으로 받아 설치하고,
macOS 는 받는 페이지를 열어 줍니다 — 서명 없는 macOS 앱은 스스로를 교체할 수 없습니다.

확인은 켠 지 20초 뒤, 그다음 두 시간마다, 그리고 자다 깨어날 때 합니다.
기다리기 싫으면 트레이 메뉴의 `업데이트 확인…` 을 누르면 됩니다.

## 키우기

**알에서 시작합니다.** 20분쯤 기다리거나 쓰다듬어 주면 깨어나는데,
누가 나올지는 깨져야 압니다. 아홉 마리 중 하나입니다.

**자주 들여다보면 빨리 자랍니다.** 하루 경험치 상한은 없습니다 — 대신 배고픔·즐거움·기운이
시간을 두고 돌아오기 때문에, 방금 돌본 아이를 다시 돌봐도 거의 오르지 않습니다.

**아홉 단계로 자랍니다.** 아기 → 어린이 → 청소년 → 어른 → 장로 → 원로 → 현자 → 영물 → 전설.
단계마다 몸이 길어지고 눈이 작아집니다. 어른을 지나면 한 단계에 표식이 하나씩 붙습니다 —
흰 눈썹(장로) → 관자놀이가 셈(원로) → 미간의 금색 표식(현자) → 반짝임(영물) → 왕관(전설).

잘 돌보면 어른은 한 달, 장로는 석 달, 전설은 열한 달쯤 걸립니다.
어른이 된 뒤로는 **두 달에 한 번씩** 칭호가 바뀝니다.

**어떻게 키우느냐가 그대로 남습니다.**

- **밥과 간식** — 밥은 한식 · 양식 · 중식 · 일식, 간식은 쿠키 · 과일 · 우유 · 육포 · 아이스크림.
  종류마다 배부름 · 살 · 즐거움이 다릅니다. **같은 걸 연달아 주면 시들해지고**,
  많이 먹인 것이 그 아이의 **입맛**이 되어 그걸 주면 더 좋아합니다.
  처음엔 한식과 쿠키만 할 줄 압니다 — **차려주다 보면 하나씩 늘어납니다**
  (양식은 밥 8번, 중식 20번, 일식 40번). 요리는 아이가 아니라 당신이 배우는 것이라,
  집 전체 횟수로 세고 새 아이를 들여도 그대로입니다.
- **놀이** — 공놀이 · 숨바꼭질 · 줄다리기 · 원반던지기. 즐거움도 드는 기운도 다릅니다.
  원반던지기는 살이 제일 잘 빠지지만 지쳐 있으면 못 하고, 숨바꼭질은 기운이 얼마 없을 때
  쓰는 것입니다. 이것도 놀아주다 보면 늘어납니다(숨바꼭질 6번, 줄다리기 15번, 원반 30번).
- **무게** — 간식을 많이 주면 몸이 넓고 낮아지고, 많이 놀아주면 길쭉해집니다.
  양식만 먹인 아이와 일식만 먹인 아이는 눈에 띄게 다른 몸이 됩니다.
- **성격** — 쓰다듬으면 `다정`, 놀아주면 `활발`, 간식만 주면 `먹보`, 재우기만 하면 `느긋`.
  성격은 대사만 바꾸는 게 아니라 배고픔·즐거움·에너지가 닳는 속도를 바꿉니다.
- **재주** — 앉아 · 손 · 엎드려 · 빙글 · 점프 · 인사 · 기다려 · 하이파이브 · 구르기 · 노래.
  잘 놀아주고 아껴준 아이가 빨리 배웁니다. 보여줄 때마다 조금씩 자라고,
  **아는 게 많을수록 한 번이 더 큽니다** — 다만 이미 신나 있으면 해주기만 하고 배우지는 않습니다.

**어른 둘이면 아이가 생깁니다.** 부모 털색을 섞은 세상에 하나뿐인 색으로 태어나고,
부모의 재주를 최대 두 개까지 물려받습니다. 가계도에 남습니다.
여덟 살부터이고, 한 번 낳으면 사흘을 쉽니다.

**한 아이에게 짝은 하나뿐입니다.** 한 번 맺으면 그 아이와만 다시 낳습니다.
**핏줄이 닿으면 맺어지지 않습니다** — 부모·자식, 형제, 삼촌·조카, 사촌까지.
조상을 하나라도 나누면 막힙니다. 대신 서로 남남인 두 집안의 아이끼리는 됩니다.
막힌 상대도 목록에는 남고, 왜 안 되는지가 적힙니다.

**집을 꾸며 줄 수 있습니다.** 돌보기 창의 `꾸미기` 탭에서 집에서 지내기를 켜면 창이 넓어지고,
뒤쪽 배경 · 바닥 · 왼쪽 · 오른쪽 네 칸을 채울 수 있습니다.
스물네 가지 중 열다섯이 이정표 상품이고, 아직 못 받은 것도 목록에 남아 어느 이정표가 주는지 보여줍니다.
집에 있는 동안에는 책상을 돌아다니지 않습니다.

털 색 · 눈 · 소품 · 집 · 대표 칭호는 모두 이 `꾸미기` 탭에 있습니다.

**이정표가 열다섯 있습니다.** 아홉은 키우는 일(어른·장로 위의 넷·전설·재주 다섯·산책 스무 번·아이·아홉 마리),
여섯은 해온 일이 쌓인 것(재주 열 개·밥 백 번·치우기 쉰 번·재주 백 번·산책 백 번·세 마리).
뒤의 여섯은 집에 있는 모든 아이의 횟수를 합쳐 셉니다. 돌보기 창에 `64 / 100번`처럼 진행도가 보이고,
달성하면 소품과 집 꾸미기 아이템, 칭호를 줍니다.

상품에는 **어디에서 고르는지**가 같이 적힙니다 — `졸업 모자 → 꾸미기 · 머리`,
`러그 → 꾸미기 · 바닥`. 이름만 알려 주면 어느 자리를 열어야 하는지 알 수 없습니다.

**칭호는 하나만 내겁니다.** 이정표를 달성하면 칭호가 쌓이고, 그중 대표 하나를 골라
말풍선과 돌보기 창 이름 옆에 답니다 — 돌보기 창의 `꾸미기` 탭에서 고릅니다.

밥·간식·놀기는 펫 위에 뜨는 막대에서 바로 고를 수 있습니다 — 버튼을 누르면
무엇을 줄지 펼쳐집니다. **지금 할 수 없는 것은 잠기고 왜 안 되는지가 적힙니다**
(`배가 불러요`, `너무 지쳤어요`).

돌보기 창(⌘K)은 다섯 탭입니다.

| 돌보기 | 상태 · 산책 훈련 재우기 치우기 · 밥 간식 놀기 · 재주 |
| 성장 | 지금과 다음 단계, 다음 칭호까지 남은 날, 이정표, 기록 |
| 가족 | 만난 친구, 짝, 가계도 |
| 꾸미기 | 털 색 · 눈 · 소품 · 집 · 대표 칭호 |
| 설정 | 말 걸기 · 밤에는 재우기 · 자리 비우면 재우기 · 펫 크기 · 구글 캘린더 |

## 구글 캘린더

돌보기 창의 `설정` 탭(⌘,)에서 구글 계정을 연결하면 다가오는 일정을 알려줍니다.
읽기 권한(`calendar.readonly`)만 요청하고, 토큰은 OS 키체인에 암호화해 보관합니다.

직접 빌드해서 쓰시려면 구글 클라우드 콘솔에서 **데스크톱 앱** OAuth 클라이언트를
만들어 저장소 루트에 `google-client.json`으로 두세요. 이 파일은 커밋되지 않습니다.

```json
{ "clientId": "...", "clientSecret": "..." }
```

## 구조

| 파일 | 하는 일 |
|---|---|
| `main.js` | 창·트레이·메뉴·설정, 모든 것을 잇는 곳 |
| `renderer/care.html` | 돌보기 창 다섯 탭 — 설정까지 여기 있습니다 |
| `care.js` | 키우기 규칙 전부. 화면 없이 테스트됩니다 |
| `family.js` | 누가 누구의 핏줄인지, 누구에게 짝이 있는지 |
| `missions.js` | 이정표 열다섯과 그것이 붙잡고 있는 상품들 |
| `chatter.js` | 펫이 하는 말 |
| `calendar.js` · `google-auth.js` | 구글 캘린더와 OAuth |
| `updater.js` | 새 버전 확인 |
| `renderer/pixel.js` | 도트맵 → SVG 컴파일러 |
| `renderer/species.js` | 아홉 종과 성장 단계별 변형 |
| `renderer/gear.js` | 소품 네 슬롯 |
| `renderer/room.js` | 집 꾸미기 네 슬롯 |

그림은 전부 코드입니다. 이미지 파일이 아니라 48×48 도트맵을 `<rect>`로 펴서 그립니다.
`shape-rendering="crispEdges"`라 어떤 크기에서도 뭉개지지 않습니다.
