Moka Pet — macOS 설치 방법
================================

이 폴더의  설치.command  를 두 번 누르면 끝납니다.
앱을 응용 프로그램 폴더에 넣고, macOS 가 막는 표시를 떼고, 실행까지 합니다.


"'설치.command'을(를) 열지 않음" 이라고 막힌다면
--------------------------------------------

    ⚠  파란색 [휴지통으로 이동] 을 누르지 마세요. 파일이 지워집니다.
       [완료] 를 누르고 아래 둘 중 하나로 하시면 됩니다.

macOS 15 부터는 서명 없는 스크립트를 두 번 눌러 열 수 없습니다.
(예전에 되던 "오른쪽 버튼 → 열기" 도 더는 통하지 않습니다.)


 방법 1 — 시스템 설정에서 한 번 허용하기   ※ 터미널이 부담스러우면 이쪽

    1. 막힌 창에서 [완료]
    2. 사과 메뉴 →  시스템 설정  →  개인정보 보호 및 보안
    3. 아래로 내리면 "'설치.command'이(가) 차단되었습니다" 같은 줄이 있습니다
       → 옆의 [그래도 열기] 를 누르고, 다시 물으면 [열기]
    4. 이제 설치가 진행됩니다


 방법 2 — 터미널에서 한 줄   ※ 확실하고 빠릅니다

    1. 스포트라이트(⌘Space)에 "터미널" 을 치고 실행
    2. 아래를 그대로 붙여 넣고 엔터

           bash

       ...그 다음 한 칸 띄우고, 이 폴더의  설치.command  파일을
       터미널 창 안으로 끌어다 놓으세요. 경로가 저절로 채워집니다.
       엔터를 누르면 끝입니다.

    터미널로 실행하는 것은 막히지 않습니다. macOS 가 막는 것은
    "두 번 눌러서 여는" 경우뿐입니다.


왜 이런 게 필요한가요
--------------------------------------------
이 앱은 애플 개발자 인증서로 서명되어 있지 않습니다.
서명하려면 애플에 연 $99 를 내야 하고, 사내에서 나눠 쓰는 앱이라 그러지 않았습니다.

서명이 없으면 macOS 는 인터넷에서 받은 파일에 "격리" 표시를 붙여 두고 실행을 막습니다.
설치.command 가 하는 일은 그 표시를 떼는 것뿐입니다.
스크립트를 텍스트 편집기로 열어 보시면 무엇을 하는지 전부 보입니다 — 스무 줄 남짓입니다.

바이러스 검사가 필요하시면 dmg 를 https://www.virustotal.com 에 올려 보셔도 됩니다.


스크립트 없이 직접 하고 싶다면
--------------------------------------------
    1. dmg 를 두 번 눌러 열고, Moka Pet 을 응용 프로그램 폴더로 끌어다 놓기
    2. 터미널에서:  xattr -dr com.apple.quarantine "/Applications/Moka Pet.app"
    3. 앱 실행


업데이트
--------------------------------------------
새 버전이 나오면 앱이 알려줍니다. macOS 에서는 자동으로 설치되지 않고
받는 페이지를 열어 줍니다. 받아서 이 과정을 다시 하시면 됩니다.
키우던 아이들은 그대로 이어집니다.
